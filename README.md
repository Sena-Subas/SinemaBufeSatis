# SinemaBufeSatis
This project is a Windows Forms application built using Visual Studio 2022. It allows users to purchase cinema tickets, including optional food and beverage items.

Features

A grouped interface for ticket selection, food and drinks.

A summary section displaying the total cost per customer.

An automatic calculation of the overall total cost, updated in real-time.

A payment section that summarizes the total for all customers.

How It Works

The user selects their ticket and optional items.

After each selection, the individual total is updated and displayed.

The form automatically recalculates the group total whenever new customers are added.

Users can confirm and finalize the purchase in the payment section.
